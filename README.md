# Ticket Form

A simple Next.js ticket form for sales and support.

## Features

- 📝 Modern, user-friendly sales and support ticket forms
- ✅ Real-time form validation with Zod
- 🌗 Responsive design with light and dark mode support
- 🚀 Instant deployment-ready for Vercel
- 📧 Email and file upload support
